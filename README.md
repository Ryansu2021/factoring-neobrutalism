# 十字交乘因式分解（新粗野主義版）

國中數學「二次三項式因式分解」互動教學網頁，以 **首尾相乘（a×c）→ 找兩數 → 拆項分組** 的流程，處理二次項係數不是 1 的多項式。介面採新粗野主義（Neo-Brutalism）風格。

🔗 線上使用：https://ryansu2021.github.io/factoring-neobrutalism/

## 功能

| 區塊 | 內容 |
|---|---|
| 推理分析 | 以 6x² + 7x − 3 為例，分三步驟示範：首尾相乘、找「相乘 = ac、相加 = b」的兩數、拆項與分組 |
| 自動推導 | 任意輸入 a、b、c，程式自動找出兩數並列出完整推導過程；無法在整數範圍分解時會提示 |
| 闖關挑戰 | 學生填寫最終分解結果，即時判斷對錯，並提醒負號變號、係數 1 省略等常見錯誤 |

## 使用方式

單一 HTML 檔，直接用瀏覽器開啟 `index.html` 即可，不需安裝。
